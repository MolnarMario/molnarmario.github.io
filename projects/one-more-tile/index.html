One More Tile

A cross-stitch puzzle inspired by the game Proverbs. Solving it uncovers a hidden pixel-art painting, one region at a time.

Play it here → Play it ↗ Source on GitHub ↗ Changelog

What it does

  1. Three puzzle types on one canvas. Fill-a-pix clues cover the board, with sudoku patches (4×4 up to 9×9) and picross patches whose solution is part of the painting.
  2. Every region you finish reveals the art. A content-aware watershed grows the regions along the picture's own edges, so a finished region shows a recognizable piece of the painting, not a random blob.
  3. Never a guess. Five difficulty tiers, and a verifier script checks that every tier of every painting solves by logic alone.
  4. Co-op for up to four. Split-screen on one screen, or online with a room code.
  5. Hints near where you're working. Press H and it points at a forced move close to your cursor and explains why it's forced.
  6. Nine paintings, saved as you go. Each painting autosaves separately, with a timer that remembers your time, undo, pan and zoom, and full gamepad support.
  7. One file. The whole game is a single HTML file with zero dependencies.

Made with

  • HTML
  • Canvas
  • Vanilla JS
  • Node verifier scripts
