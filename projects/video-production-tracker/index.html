Video Production Tracker

I make videos, so I built the tracker I wanted. Each project is a script split into sections.

Open the app ↗ Source on GitHub ↗ Commit log

What it does

  1. Know what's filmed and what made the edit. Every script section has its own filmed and edited checkboxes, so nothing gets forgotten between shoot and cut.
  2. Progress at a glance. Progress bars for filming, editing and publishing, per project and overall.
  3. Track where it went live. Publishing status per platform: YouTube, LinkedIn, Facebook, Instagram and TikTok.
  4. Write the script in place. Quick-add templates for hooks, intros, main points, B-roll and calls to action, with a rich-text editor per section.
  5. Safe local storage. Everything saves to the browser with a versioned schema. JSON backup and restore checks the file before touching your data.

How it was built

It was planned up front: the data model, how progress is worked out across the production stages, how storage and backups behave, and a phased roadmap, all written down in a plan that went in with the first commit on 23 August 2026.

Decisions that mattered

  • Progress that doesn't mislead. Overall progress weights filming at 40%, editing at 40% and publishing at 20%, so a project with many script sections doesn't drown out its publishing.
  • Check a backup before touching your data. An imported file is parsed, and its projects, sections and platform states are validated and repaired. You see how many projects it holds before you choose to merge or replace.
  • Rich text, sanitized. Each script section has a rich-text editor, and its HTML is sanitized before it's saved.

Where it stands

Live. Everything stays in your browser.
