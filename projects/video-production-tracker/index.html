Video Production Tracker

I make videos, so I built the tracker I wanted. Each project is a script split into sections.

Open the app ↗ Get started Source on GitHub ↗ Commit log

What it does

How a video actually gets made, one stage at a time.

01

Write the script in sections

Every video I make has a hook, an intro, a few main points and a call to action, and each part has a life of its own after the script is written.

  • Quick-add templates. Sections for a hook, an intro, main points, B-roll and a call to action, or your own.
  • A rich-text editor per section. Bold, italics and lists, with sections you can rename and reorder as the script changes.

02

Know what's filmed and what made the edit

Sections get filmed on different days and cut in later, and a to-do list loses track of which one is still missing from the edit.

  • Two checkboxes per section. Filmed, and inserted into the edit, so nothing gets forgotten between the shoot and the cut.
  • Progress at a glance. Bars for filming, editing and publishing, per project, and an overall figure that doesn't let a long script drown out its publishing.

03

Track where it went live

A finished video goes out to five platforms, not one, and they rarely all happen on the same day.

  • Publishing per platform. YouTube, LinkedIn, Facebook, Instagram and TikTok, each marked draft or published.
  • Projects that end properly. Mark a project completed, or scrap it. Scrapped projects are archived, not deleted, and can be restored.

04

Safe in your browser

There is no account and no server, so everything stays on your device, and the backup has to be trustworthy.

  • Saved as you type. Everything is stored in the browser with a versioned schema.
  • Backups checked before they touch your data. An imported file is validated and repaired, and you see how many projects it holds before choosing to merge or replace.
  • Light and dark. Plus a font picker that previews each option.

Get started

It runs in the browser with no account and nothing to install. Your projects stay in that browser.

  1. Open the app. Go to video.thebarbellengineer.com.
  2. Start a project. Click New Project and give the video a title.
  3. Write the script. Add sections with the quick-add templates and write each one.
  4. Tick as you go. Mark each section filmed and inserted, then each platform as published.
  5. Back it up. Use Backup / Restore in the header now and then. Clearing site data or switching browsers starts empty until you restore.

How it was built

It was planned up front: the data model, how progress is worked out across the production stages, how storage and backups behave, and a phased roadmap, all written down in a plan that went in with the first commit on 23 August 2026.

Decisions that mattered

  • Progress that doesn't mislead. Overall progress weights filming at 40%, editing at 40% and publishing at 20%, so a project with many script sections doesn't drown out its publishing.
  • Check a backup before touching your data. An imported file is parsed, and its projects, sections and platform states are validated and repaired. You see how many projects it holds before you choose to merge or replace.
  • Rich text, sanitized. Each script section has a rich-text editor, and its HTML is sanitized before it's saved.
