Version 0.55.0

Oct 29, 2026

  • The New Workspace dialog has a Lanes box. Tick it and the workspace starts with Lanes on, so the first Claude agent you add gets its own lane and you can make it the integrator right away. It needs a git repository, and a GitHub clone always is one.
  • In New Workspace, an existing folder no longer leaves an empty gap sized for the GitHub fields.

Version 0.54.1

Oct 29, 2026

  • A program a Claude agent starts through Git Bash, like a dev server, now ends when you stop or close the agent, or when it goes to sleep. Before, it kept running on its own, and the gear on the card never showed it.
  • A background command an agent starts in its first 16 seconds now lights the gear, so sleep leaves that agent awake instead of ending the command.
  • The time an agent was last active is saved as soon as it changes, not up to 20 seconds later.

Version 0.54.0

Oct 28, 2026

  • New in Options: Free up RAM. Sleep inactive agents stops an agent that has been idle for an hour, or for up to 24 hours if you set it, so its memory goes back to Windows. Its card turns black with the conversation's summary, its dot in the sidebar turns gray, and a click resumes the same conversation. An agent that is working, asking you something, running a command or holding a prompt you haven't sent is never put to sleep. It is off until you turn it on.
  • Keep them asleep at startup, on as soon as you turn sleep on, leaves agents that were asleep or idle that long asleep when AI Hive opens instead of starting them all. Turn it off and every agent resumes at startup, as before.

Version 0.53.2

Oct 26, 2026

  • The context badge on a Claude card drops as soon as the conversation compacts, instead of showing the old, full reading until the next turn.

Version 0.53.1

Oct 26, 2026

  • Copying text from a Claude agent's window keeps a wrapped paragraph as one line, so a reply or prompt pastes the way Claude wrote it instead of breaking at every row. Tool output still keeps every line.

Version 0.53.0

Oct 26, 2026

  • Restart to update now restarts AI Hive for you. It saves, closes and opens the app again. If agents are still working, waiting on you or running a command, it lists them first: Restart now interrupts them, Wait keeps them running and the button counts down what is left. The update dialog has a Restart now button too.
  • Shift+Arrow, Home and End grow a selection you made in an agent's history where it is, instead of jumping back to the live screen.
  • The sidebar no longer leaves the gold name on a workspace you just switched away from.

Version 0.52.0

Oct 25, 2026

  • Dragging a selection past the top or bottom of an agent's window now scrolls through its history and keeps selecting, faster the further past the edge you hold the pointer. The selection also stays on its text when you scroll with the wheel or the scrollbar.
  • Menus and dropdown lists open at once instead of fading or sliding in.

Version 0.51.0

Oct 23, 2026

  • Bold word starts is now called Bionic reading, and its tooltip explains how a bold start helps some readers keep their place in a line.
  • Boldness is now called Contrast, and Options shows it only while Bionic reading is on.
  • With Bionic reading on, the line you are typing no longer turns bold when its text fills a row and the caret moves to the row below.

Version 0.50.0

Oct 23, 2026

  • Changing the terminal font or letter spacing no longer flickers through the old screen in the new font. Each terminal on screen shows "applying the new font" until the agent has redrawn, at most 3 seconds.
  • Options > Terminal font ends with "Load a custom font...". It takes .ttf, .otf and .ttc files, explains why it refused anything else, and keeps the font across restarts.
  • Bold word starts has a Boldness setting from 1 to 5 under the switch. Level 1 is the old plain bold, level 2 draws a heavier bold, and levels 3 to 5 also fade the rest of each word. It starts at 3, and each terminal font remembers its own level.
  • Dropdowns open below their box instead of covering it.
  • The New Agent dialog keeps one width while its conversation list loads. Long conversation previews are cut short in the list and show in full in their tooltip.

Version 0.49.0

Oct 23, 2026

  • Options > Appearance has a Terminal font picker and Letter spacing for the agent terminals. Pick Cascadia Mono, JetBrains Mono NL, IBM Plex Mono, Atkinson Hyperlegible Mono or OpenDyslexic Mono, or Theme font for the skin's own (Share Tech Mono in Adeptus Mechanicus). Default keeps Consolas, so nothing changes until you pick. Letter spacing adds 0 to 3 px between letters, and box-drawing lines stay solid at any spacing.
  • A new Bold word starts switch in Options > Appearance draws the first half of each word in bold in every terminal. Code, paths, links and the line you are typing keep their regular weight. It starts off.
  • The New Agent model list matches Claude's own /model menu, older models included (Opus 4.8, Sonnet 4.6 and the rest). The "[1m]" entries are gone: Opus, Sonnet and Fable already run with a 1M context window. Agents saved on one still launch as before.
  • The Default model and effort entries in New Agent say what Claude will run, for example "Default (high, saved by /effort)". Default uses the last pick /model or /effort saved in any terminal, which looked like the previous agent's settings carrying over.
  • Answering one of Claude's question forms puts a dot on the terminal scrollbar, a yellower shade of your prompt dots, so you can scroll back to what you answered.

Version 0.48.1

Oct 22, 2026

  • An agent you closed before typing anything to it comes back as a fresh session. It used to show "No conversation found with session ID" above its prompt, and in a folder with other conversations it could come back holding another agent's chat.
  • When the window stops responding for 3 seconds or more, AI Hive writes where it was stuck to hang.log, next to your session file. The next launch moves it to hang.log.1, so a freeze you had to close AI Hive in keeps its record. Attach both to a report of a freeze.

Version 0.48.0

Oct 22, 2026

  • At launch AI Hive starts the agents of the workspace it opens on first. Agents in your other workspaces wait until those have their prompt, then start two at a time, and opening one of those workspaces starts its waiting agents straight away. Starting all of them together used to freeze the window for up to 1.2 s while the agents in front of you loaded. A card still waiting shows its loader, and closing AI Hive before it starts brings it back next launch.

Version 0.47.0

Oct 21, 2026

  • Opening AI Hive no longer waits on GitHub. It used to fetch and install updates before showing a window, which took about a second on every launch. Now a new Options switch, Update AI Hive in the background (on by default), checks a minute after the window opens and then every hour. It installs a newer version while you work, the button by the version number reads "Restart to update", and the next launch runs it. An update that needs new Python packages waits for your click, and so does a folder that is off main or has local changes. Switched off, only the button checks.
  • The launch no longer copies your agents' conversations or scans them for plan-limit stops on the window's thread. Both run in the background while the window builds, which took about 0.6 s of freezing off the launch. Agents still wait for the backup copy before they start.

Version 0.46.1

Oct 21, 2026

  • The New Agent dialog opens without waiting for its list of past conversations. The list loads in the background while the resume picker says "Loading conversations", and OK stays off for a Claude agent until it arrives, so Enter can't start a fresh conversation you meant to resume. Over a folder with 131 conversations, the first opening went from about 400 ms to about 80 ms.

Version 0.46.0

Oct 21, 2026

  • AI Hive opens much faster when you have many workspaces and agents. The saved theme and console font now apply before the window is built, instead of restyling every widget and redrawing every terminal after it, and the sidebar builds once instead of once per workspace. On a copy of a 15 workspace, 18 agent session, building the window went from 14 to 18 seconds down to 2 to 3.
  • A new agent starts at its card's real size. It used to start at 100 columns by 30 rows and redraw when the card's size caught up, and a conversation resumed from the New Agent dialog stayed wrapped at 100 columns in the scrollback.
  • Each launch writes a PERF startup line to session.log with how long every step took, and a PERF stall line whenever the window freezes for more than 150 ms, naming the terminal output or redraw behind it. Nothing changes on screen.
  • Claude's install is looked up once per launch instead of once per agent, and the tooltip handler starts after the window appears, which trims a little more off the launch.

Version 0.45.3

Oct 21, 2026

  • The Adeptus Mechanicus theme has a new aquila crest: a double-headed eagle in phosphor green on a dark glass plate with a green edge. The old grey crest was hard to make out. The new one stays sharp at 150% display scaling.

Version 0.45.2

Oct 20, 2026

  • A Claude card taller than 48 rows keeps its scrollback when the card changes size. It used to lose everything above the last screenful, in resumed conversations and open ones alike, so the scrollbar went away and the mouse wheel did nothing.

Version 0.45.1

Oct 19, 2026

  • A long Claude reply no longer shows up two or three times over in a card's scrollback. When Claude redraws a reply taller than the card (after the idle recap, closing Ctrl+O, or coming back to the terminal), the rows that scrolled off a second time are copies, and AI Hive now drops them.

Version 0.45.0

Oct 19, 2026

  • Ctrl+F in a terminal opens a find box in its top right corner, like Chrome's page search. It searches the agent's whole history as you type, ignoring case, paints every match yellow and the current one orange, shows how many there are and marks each one on the scrollbar. Enter or F3 goes to the next match, Shift+Enter or Shift+F3 to the previous one, and Esc closes the box. Text you selected becomes the search. A phrase the agent wrapped onto two rows is not found. In a full-screen program such as less or vim, Ctrl+F still goes to the program.
  • A mouse wheel over a terminal's scrollbar reaches an agent that tracks the mouse at the spot under the pointer. It used to reach it at the terminal's left edge.

Version 0.44.3

Oct 17, 2026

  • In the Illuminated Manuscript and Adeptus Mechanicus themes, the top bar's buttons and pills sit in the middle of the header. They used to sit closer to its bottom edge.
  • The Adeptus Mechanicus aquila plaque is smaller and stays on the top border, so it no longer hangs over the usage pills.

Version 0.44.2

Oct 17, 2026

  • The + that picks which usage pills to show sits in the middle of its square. It used to sit low and to one side.
  • The sidebar collapse and expand button in the top bar is bigger, so its panel and arrow are easier to make out.

Version 0.44.1

Oct 17, 2026

  • The usage pills say "checking..." at launch instead of "unreadable" when the Claude login expired during a long break. AI Hive checks again every 2 seconds and fills the pill in as soon as the first Claude agent renews the login, instead of waiting up to 6 minutes.
  • The gear on an agent card no longer lights up from launch on for nearly every agent. It counted AI Hive's own activity log helper, which Claude starts a little later, as a background process.
  • With a terminal focused, the Win+V clipboard panel and the Win+. emoji panel now take the arrow keys, Enter and Esc. Before, those keys went to the agent and the panel couldn't be driven or closed from the keyboard. An emoji picked in the panel is typed into the agent. The panels open at the terminal's cursor, and a Japanese, Chinese or Korean input method works in a terminal, showing what you compose at the cursor until you commit it.

Version 0.44.0

Oct 16, 2026

  • Ctrl+Tab moves to the next agent in the workspace, left to right along a row and then down to the next row, wrapping back to the first. Ctrl+Shift+Tab goes the other way. If an agent is maximized, the next one takes its place.
  • Options > Help > Keyboard shortcuts lists every shortcut AI Hive has.
  • The button at the top left that hides the sidebar now shows which way it will go: an arrow pointing left while the sidebar is open, right while it is hidden. Its tooltip names the action and the shortcut.
  • Fullscreen (F11) no longer leaves a thin strip of wallpaper at the window's edges, and neither does the maximized window you return to.

Version 0.43.3

Oct 16, 2026

  • Hovering a category in the sidebar now shows plainly which one the pointer is on: the header gets a visible tint, its arrow lights up in the accent colour and its count brightens. The category's outline stays visible under the tint instead of disappearing.
  • An agent no longer shows a "?" when it hasn't asked anything. Claude sometimes signals a question it never asks, and the "?" then stayed lit on an agent that was done. AI Hive now waits until the question is actually in the conversation before it shows the "?".

Version 0.43.2

Oct 16, 2026

  • A narrow card header no longer cuts its chips off mid-word, such as "Opus 5.5 · high ·" or "10% of 1". As the card narrows, the header drops whole words in a fixed order: the task summary shrinks to a clipboard icon, then the word integrator goes, then the model's mode and effort, then the " of 1M" of the context badge, then the lane counts.

Version 0.43.1

Oct 15, 2026

  • A crowded card header no longer shortens the integrator's lane chip to "int...tor". The chip drops whole words instead, the word integrator first since its icon already says it, then the counts. The chip's tooltip still lists the role and every count.

Version 0.43.0

Oct 15, 2026

  • Giving an agent its own lane, from the New Agent dialog or Restart in own lane, now turns the workspace's Lanes toggle on, so the header no longer says Lanes is off beside a laned card.
  • Make integrator works on an agent without a lane once the workspace has a lane. After you confirm, the agent restarts in its own lane in a new conversation and becomes the integrator.
  • The + that brings back closed usage readouts is now a square button with the same bold + as the add workspace button.

Version 0.42.1

Oct 13, 2026

  • After a usage limit, Claude Code's own "continuing automatically" gets to go first. AI Hive used to type Continue a few seconds after the reset, which cancelled Claude's own continuation. Now it waits until 7.5 minutes past the reset and steps in only if Claude hasn't continued.
  • Pressing Esc on Claude's automatic continue now also tells AI Hive not to resume that agent.
  • Before it continues a Claude agent whose reset time has passed, AI Hive checks the account's usage reading and keeps waiting while the limit is still spent. With no fresh reading, it waits up to 10 minutes, then goes by the clock as before.

Version 0.42.0

Oct 12, 2026

  • The Close merged agents dialog has a "Don't ask again" box, with a switch under Options > Agents (Confirm Close merged agents) that brings the dialog back.
  • Closing several merged agents at once fades their cards out in turn and rearranges the grid once, instead of once per agent.
  • Pressing F11 to leave fullscreen goes straight back to a maximized window, without flashing at half size first.

Version 0.41.2

Oct 12, 2026

  • The usage pills keep loading at startup when the first read fails and say "retrying..." while they try again within seconds. They only show that usage could not be read after 3 minutes of failures, or right away for an expired login.
  • A new agent in its own lane shows the loading animation while AI Hive creates its git worktree, instead of "terminal not running".

Version 0.41.1

Oct 11, 2026

  • An agent that writes about the usage-limit menu in its own reply no longer gets the hourglass. Only the real menu counts.

Version 0.41.0

Oct 11, 2026

  • Ctrl+Up maximizes the selected agent and Ctrl+Down shows every agent again. A focused terminal no longer receives these two keys.
  • A Claude card's usage-limit hourglass no longer comes back after a resume when Claude redraws the old limit message. A limit the conversation never recorded clears after 10 idle minutes.

Version 0.40.0

Oct 11, 2026

  • Resizing a Claude terminal re-wraps its whole scrollback at the new size, not just the bottom screenful. The reflow waits until the agent is idle.
  • A reply paragraph no longer shows up twice in a Claude card's scrollback after Claude redraws its screen while idle.
  • Closing a Codex agent no longer kills the Codex daemon that your other Codex windows share.
  • Codex's own daemon and MCP servers no longer light the gear badge, and the gear's kill menu no longer offers them.
  • Clicking a workspace in the sidebar or in the event log puts the cursor in its top-left agent (or the maximized one), so you can type right away.
  • The New Agent dialog shows the Full terminal box only for shells, scripts and custom commands. It was a forced, greyed-out tick for AI agents.
  • A task summary squeezed down to a lone ellipsis in a card's header turns into a clipboard icon that shows the whole task on hover. The close button is square and the usage text next to it is larger.

Version 0.39.1

Oct 10, 2026

  • A Codex card now shows the "?" when Codex asks for approval or asks a question, and stops pulsing as busy while it waits for your answer.

Version 0.39.0

Oct 10, 2026

  • Before a laned agent marks its work Task done, it merges the newest main into its lane and gets a GPT-6-Luna code review, fixing what the review finds. Lanes reach the integrator already up to date and reviewed.
  • Agents already running keep the old instructions until they restart.
  • After a restart, the newest reply of a reopened conversation gets its time stamp again, even when the reply was reprinted slowly or the card was cleared.

Version 0.38.1

Oct 9, 2026

  • Opening or closing the sidebar no longer lights every idle agent as working for two seconds.
  • The README explains the lane chip's counts, untracked files and its hover tooltip.

Version 0.38.0

Oct 9, 2026

  • Tooltips wrap at one readable width instead of stretching into a thin strip across the window. A new Tooltips switch in Options turns them all off.
  • Options has a Fullscreen switch that does the same as F11.
  • F11 no longer opens a black console window when pressed right after AI Hive starts.
  • In fullscreen, resting the cursor on the top or left edge brings the bars back in 0.75 s instead of 1.5 s, and the floating top bar leaves out the logo, name and version.
  • A Claude reply no longer shows up several times over in a card after the card changes width.
  • Close merged agents closes every merged agent in one click, not one per click.
  • A finished lane's chip judges conflicts by the commit it flagged as done, so later unfinished work no longer turns a shippable lane red.
  • The Claude model list says Haiku 5.5 instead of Haiku 4.5.

Version 0.37.2

Oct 9, 2026

  • The icons in a card's hover tray are now one size, the maximize button included, and the "⋯" that opens the tray is bigger.
  • Make integrator is no longer offered while the workspace already has an integrator. Stop the current one first to hand the role on.
  • The lane chip on a card shows a drawn branch icon instead of the small "⎇" glyph. The integrator's chip shows two lanes merging into one.
  • The folder and trash beside the workspace path are line icons that match Lanes, Layout, Map and Activity, and the path is easier to read.

Version 0.37.1

Oct 9, 2026

  • The new terminal shortcut is now Ctrl+T instead of Ctrl+N, so Ctrl+N goes back to the program running in the terminal.
  • The maximize and restore button on a card is now four plain arrows, a little larger than before.

Version 0.37.0

Oct 9, 2026

  • F11 goes fullscreen with only the agent grid on screen. Rest the pointer on the top edge for a moment to float the top bar and the workspace header over the grid, or on the left edge for the sidebar. Terminals never resize when they appear. F11 again puts the window back as it was.
  • Ctrl+N opens a new terminal, also while a terminal has focus.
  • Reply time stamps no longer vanish when a card is resized, retiled or rebuilt. They now work for Codex and Gemini agents, and a reopened Codex conversation gets its stamps back. Options > Reply times hides them.
  • The card's maximize button draws corner arrows, pointing out to maximize and in to restore, in the theme's header colors.

Version 0.36.1

Oct 7, 2026

  • Restart now gives the new agent a blank screen. The new Claude used to draw its banner and input box over the old one's last frame.
  • The card's maximize button uses the Windows caption icons: one square to maximize, two stacked squares to restore. They are larger than the old arrows, which looked alike.

Version 0.36.0

Oct 7, 2026

  • Close merged agents on the integrator's lane chip closes, after you confirm, every agent whose lane work is now on main and that holds nothing else: no commit ahead, no uncommitted file, not mid-turn. Their lanes go too. The integrator and every other agent stay open.
  • The Ship finished lanes confirmation has a Don't ask again box. Options

    Agents > Confirm Ship finished lanes turns the question back on.

  • Stop is gone from a terminal card's hover tray. Ctrl+C in the terminal does the same. Line-console cards, which have no Ctrl+C, keep it. Restart on a running agent now shows a restarting veil until the new prompt is live, instead of a frozen old frame.
  • A finished lane that shares a file with another lane keeps its green chip and gets a yellow border, instead of turning amber. Lane chips have squarer corners.
  • The model badge no longer shows backticks or a cut-off name like "Sonnet 5" after a /model pick.
  • The agent map's hub colors match the sidebar: green when idle, yellow while working.
  • Show usage moved to the left column in Options, under the chime rows.

Version 0.35.0

Oct 7, 2026

  • Click the integrator's lane chip and pick Ship finished lanes to ask it to ship. The item counts the lanes with a Task done commit, shows you the list to confirm, then types the request into the integrator. It stays greyed out while the integrator works or no lane is finished.
  • The test suite runs in parallel worker processes and finishes in about a minute and a half instead of six. It also stops leaving test folders behind in your Temp folder.
  • Old plan and review documents are gone from the project folder.

Version 0.34.1

Oct 6, 2026

  • Removes the old task hand-off code that 0.34.0 left without a button. Nothing you can see changes: scheduled sends and the auto-continue after a plan limit still type into agents the same way.
  • The collapsed sidebar rail and the workspace count badges now share one "working" pulse, so they breathe in step.

Version 0.34.0

Oct 6, 2026

  • Restart now gives you a fresh agent, as if you closed the card and opened a new one of the same kind. It drops a permission mode you switched into, a /model or /effort override, the AI title, the context badge and the assigned task. Name, folder, lane, font and the model, effort and permission mode you created it with stay.
  • The Start and Assign buttons are gone from the card's hover tray. Restart or any keystroke starts a stopped agent.
  • A collapsed sidebar now leaves a thin rail with one strip per workspace, colored like its count badge: amber while an agent works, green when idle, red on an error. Hover a strip for the name and counts, click it to open that workspace.
  • New "Show usage left" switch under Options, Appearance. Usage pills then read "Claude 79% left" instead of "Claude 21% used", and the ring empties as you use up the window. Red still means 85% used.

Version 0.33.0

Oct 6, 2026

  • The integrator no longer pulls main into your project's own folder after it merges. That folder is your working copy, and a pull could change files under your editor or dev server. It tells you main moved instead, so you pull when you're ready.
  • The integrator no longer bumps a version or edits a CHANGELOG in every project. It does both only when the project's docs/agents/integration.md asks for it, the way AI Hive's own does.

Version 0.32.0

Oct 6, 2026

  • You decide when finished work ships. AI Hive no longer types a note into the integrator each time a lane's agent commits "Task done". The lane chip still gets its ✓ and turns green. When you think there is enough for a pull request, ask the integrator to ship it, naming the lanes you want or none for everything marked done.
  • The integrator starts only when you ask it to, never on its own.

Version 0.31.0

Oct 6, 2026

  • A lane's chip on its card turns green once its agent commits "Task done". Amber or red for files another lane also changed still wins over green.
  • The workspace header's buttons are evenly spaced again. Change and Layout had a 20px gap between them while every other pair sat 6px apart.
  • The header's Change… button is now called Change folder.

Version 0.30.0

Oct 6, 2026

  • Finished work now ships without any clicks. When a laned agent finishes its task, it commits with a last line of just "Task done". AI Hive sees that commit, puts a ✓ on the lane's chip and tells the integrator. The integrator combines every finished lane into one pull request, runs the tests, gets a GPT-6-Luna code review, fixes what it finds and reviews again until the review is clean. Then it merges and updates your main folder, so the next launch runs the new version.
  • The integration queue is gone: no more Submit to integrator, Approve merge, Mark merged or the Activity panel's Integration section. Your integrator stays the integrator. Queue items saved by an older version are dropped when the session loads.
  • A laned agent now commits each finished task on its own, without asking. If it ends a turn with uncommitted changes anyway, it gets one reminder to commit them.
  • When a closed card's lane is kept only because of uncommitted files, the notice names up to three of them.

Version 0.29.0

Oct 6, 2026

  • The card actions that lived in the header's right-click menu (start, stop, restart, assign a task, scheduled send, Restart in own lane, Make integrator) are now buttons in the tray that opens when you hover the ⋯ in a card header, next to A- / A+ / maximize. Each has a tooltip naming it. The right-click menu is gone. A lane action AI Hive can't do right now shows disabled, and its tooltip says why.
  • The hover tray closes when you move the pointer slowly off it, up or down. Before, it could stay stuck open on a display with fractional scaling.
  • A second click on a dropdown's button now closes the dropdown. Before, it closed and opened again at once. This affects the repo activity arrow, the usage "+" picker, the chime rows' note button in Options, and the background-shell and lane chips.
  • A click anywhere on a sidebar category row expands or collapses it, not only on the arrow. A double-click on the name still renames it.
  • The Activity panel's "No integrator yet" hint points at the ⚑ button in the card's hover tray instead of the right-click menu that is gone.

Version 0.28.5

Oct 6, 2026

  • Closing an agent no longer says "Lane kept" with an unmerged commit when that work is already on main as a different commit. This happened when the integrator cherry-picked a lane into a batch, and after a squash or rebase merge. AI Hive now removes the lane once every change in it is on main. A lane with even one change main lacks is still kept.

Version 0.28.4

Oct 6, 2026

  • AI Hive pulls what merged on GitHub every time it starts, so a restart always runs the latest approved changes. Before, nothing moved your folder after a merge, and a folder left on an old branch never updated at all. It still never touches local changes or commits that are not on GitHub.

Version 0.27.0

Oct 2, 2026

  • Agent lanes get an integration queue. Right-click a laned Claude agent's header and pick Make integrator, then choose Submit to integrator on another lane's chip. One lane at a time, AI Hive sends the integrator a short brief: it merges the newest base branch into that lane's work, bumps the version, runs the tests on exactly that commit and opens a pull request that names it. It never merges.
  • The Activity panel's new Integration section lists every submitted lane. Approve merge there is the only way a pull request gets merged, and AI Hive does it itself: it refuses if the pull request changed since it was tested or the base branch can't be confirmed with GitHub, and sends it back to the integrator if the base branch moved since then. Anything unexpected waits for you with the reason and the "?" chime, and is never approved again by itself.
  • A pull request merged on GitHub instead of with Approve merge waits for you: Mark merged checks with GitHub, then moves the queue on. A lane whose work was squash-merged can be removed from its "lane kept" notice.
  • A lane with no work of its own now catches up with the base branch by itself while its agent is idle, and the agent is told.
  • The integration queue needs a GitHub remote and a logged-in GitHub CLI (gh). It pauses while Agent lanes is off and survives a restart.

Version 0.25.0

Oct 2, 2026
